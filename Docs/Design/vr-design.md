# VR Design

## Runtime
- OpenXR preferred
- SteamVR fallback
- Runtime auto-detect at startup

## Comfort
- Teleport + snap turn default
- Smooth locomotion opt-in
- Vignette during rapid motion
- Comfort/border culling during warps/teleports

## Interaction
- Hand presence for inventory/weapon draw
- Haptic feedback on swing/spell cast
- UI in world space at fixed depth
- Voice chat optional via system mic
