# Avatar Pipeline

1. Download reference art from wiki URLs above.
2. Download Sketchfab model as OBJ/FBX/glTF.
3. Import to Blender with VRM add-on.
4. Retarget to VRoid base skeleton or Humanoid meta-rig.
5. Bake textures into PBR albedo/normal/roughness/metalness.
6. Export VRM 1.0 + glTF 2.0.
7. Import into dot-hack-remake engine avatar system.
